# Support

## Getting Help

If you need help with haxcms-mcp, please use the following resources:

### Community Support

- **Discord**: Join our community Discord server for real-time help and discussion: [HAXTheWeb Discord](https://discord.gg/aCGxmRHEJP)
- **Documentation**: This repo's [README](README.md) and [tool reference](docs/tools.md), plus the [HAXTheWeb Docs](https://haxtheweb.org/documentation)
- **Issues**: For bug reports and feature requests, please use our unified issue queue and pick **haxcms-mcp** as the project: [HAXTheWeb Issues](https://github.com/haxtheweb/issues/issues)

### Getting Started

- Follow the [Install](README.md#install) and [Troubleshooting](README.md#troubleshooting) sections of the README
- Explore and play with HAX components: [HAX Magic Script Playground](https://hax.cloud/magicscript.html)
- Join the discussion on [Discord](https://discord.gg/aCGxmRHEJP) to connect with other developers

### Before Opening an Issue

Before creating a new issue, please:

1. Search existing issues in our [unified issue queue](https://github.com/haxtheweb/issues/issues)
2. Check the README's [Troubleshooting](README.md#troubleshooting) table
3. Ask for help on [Discord](https://discord.gg/aCGxmRHEJP)

This helps keep our issue queue focused on actual bugs and feature requests.
